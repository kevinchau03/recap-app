### 4DaMems (WIP Name)
This web app helps individuals cherish their memories by giving them a more interactive and meaningful trip recap.

### Getting Started
1. You can either `git clone` this repo to contribute or fork it
2. Install the dependencies using `npm install`
3. Ask one of the devs for the .env values
4. Start the local server with `npm run dev`

### The Tech Stack
Frontend: Next.js
Backend: Supabase
